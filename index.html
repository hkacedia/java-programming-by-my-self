01

소개

충북대학교에서 컴퓨터를 공부하는 학생입니다. 화면에 예쁘게 보이는 것보다, 그 뒤에서 실제로 돌아가는 구조가 더 궁금한 편이에요.

패키지로 한 번에 까는 것도 좋지만, 소스코드부터 configure → make → make install 로 직접 빌드해보면서 "왜 이 라이브러리가 필요한지"를 알아가는 과정을 재밌어합니다. 막히면 로그를 읽고, 원인을 찾고, 고칩니다.

지금은 리눅스 서버 운영과 데이터베이스를 파고 있고, 배운 걸 기록하고 작은 것부터 실제로 만들어보려 합니다.
